# Sketch Blender Preview

言語: [English](README.md) | 日本語

手描きの Blender 風 UI で 3D モデルを確認できる静的ブラウザ playground です。すべてブラウザ内で動くため、選択またはドロップしたモデルや参考画像は訪問者の端末内だけで処理されます。

## 機能

- `ファイル > モデル読込` から `.glb` / `.gltf` / `.obj` / `.fbx` / `.stl` を選択、またはビューポートへドロップ。
- `Image > Reference` から参考画像を追加、または画像をビューポートへドロップ。
- normal 表示と toon/sketch の青いアウトライン表示を切り替え。
- 左側の手描きツールで移動、回転、拡大縮小。
- Reset でモデルの位置、向き、拡大縮小を元に戻す。
- Help パネルを表示し、UI 言語を英語、日本語で切り替え。

## プライバシー

モデルと参考画像はローカルのブラウザで読み込まれます。このデモはファイルをサーバーへアップロードしません。

非公開のウサギ `.glb` モデルは、この公開リポジトリには含めていません。

## ローカル実行

```sh
python3 -m http.server 5177
```

`http://localhost:5177/` を開いてください。
